# Newsletter Composer: worked examples

Two complete examples of this skill's work. The names, companies and figures are invented: keep the structure and
the way of working, never reuse the facts.

## Example 1: First issue of a weekly company update

**Request**

> First issue of "Werkbank Weekly", our email update for all 180 employees, week 16–20 Nov 2026. 3-minute read,
> friendly, from the People Team. Sections: lead, Shipped, People, Dates. My notes:
> - New expense tool "Spesenflow" from 1 Dec; November expenses must go into the old tool by Fri 27 Nov. Guide:
>   intranet/expenses
> - Release 4.2 shipped 18 Nov: batch scheduling for production orders
> - Won the Hafenwerk Logistik contract (3 years), team: Ines Koller, Mark Stein
> - New joiners: Lea Brandt (Support), Omar Haddad (Engineering)
> - Christmas party Fri 11 Dec, 18:00, canteen Bremen
> - Canteen menu changes next week
> - Reminder: password manager rollout (we sent the announcement last week)
> - Ana from Finance has her birthday on Thursday

**How the skill handles it**

- Profile: first issue, so the profile block comes first, for the user to save and reuse.
- Step 2: the expense deadline is the lead (affects everyone, action needed, loses value if it waits); the cut list explains each omission.
- Ground rules: the birthday is personal data and stays out until the user confirms it is approved.
- Review draft: source markers stay in until the user approves.

**Answer**

**Newsletter profile (save and reuse)**

| Setting | Value |
|---|---|
| Readers | All 180 employees |
| Purpose | Keep everyone informed on what changes for them |
| Cadence and period | Weekly, Monday to Friday |
| Length | 3-minute read: 1 lead + up to 5 short items |
| Fixed sections | Lead, Shipped, People, Dates |
| Voice and brand | Friendly, direct |
| Channel | Email |
| Sign-off | "— The People Team" |

**Cut list**

- Canteen menu: affects everyone, but no action and little news; suggest the canteen page instead.
- Password manager: already announced last week; not new.
- Ana's birthday: personal data; I left it out. Tell me if birthdays are approved for the newsletter.

## Example 2: Scheduled run with too few items (German edition)

**Request**

> (Scheduled task, Friday 20 Nov 2026, 10:00, no person watching.) Instructions: "Erstelle den Entwurf für den
> Newsletter ‚Team Vertrieb kompakt' für die vergangene Woche aus #vertrieb-news, dem Teamkalender und dem CRM.
> Profil: wöchentlich, 1 Aufmacher + bis zu 4 Kurzmeldungen, Rubriken Aufmacher, Abschlüsse, Termine. Du-Form,
> Absender ‚Dein Sales-Ops-Team'." Found: Calendar: Vertriebsmeeting Q1-Planung Do 3 Dec 2026, 14:00, Raum
> Elbe + Teams. CRM: no deal closed 13–19 Nov. Channel: no posts.

**How the skill handles it**

- "Running on a schedule": no questions; the period is the seven days before the run (13–19 Nov).
- Only one item turned up, so instead of padding the issue it writes a short note with what it found.
- Fixed sections: the profile does not say how to handle an empty section, so that goes under "Needs your input".
- German edition, du-form as the profile sets.
