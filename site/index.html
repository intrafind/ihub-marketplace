Getting started

From zero to your first installed app in three steps.

  1. 1

    Run iHub Apps

    Install iHub with the one-line installer, run the Docker image, or download a standalone binary. iHub configures itself on first start.

    curl -fsSL https://raw.githubusercontent.com/intrafind/ihub-apps/main/install.sh | sh
    docker run -d -p 3000:3000 -v $(pwd)/contents:/app/contents ghcr.io/intrafind/ihub-apps:latest

    Getting started guide Installation options Releases

  2. 2

    Open the marketplace

    Open http://localhost:3000, sign in as an administrator, and go to Admin → Marketplace. The iHub Official Marketplace registry is already configured.

    Registry missing on an older install? Choose Manage Registries → Add Registry and paste the registry URL above.

  3. 3

    Install content

    Pick an item and click Install. Apps, prompts, skills, and workflows are ready right away; models need an API key for their provider, set in Admin → Models or as an environment variable.

    Tip: connect your iHub on this page and every item gets a button that opens it in your iHub admin panel.
